# Retail Sales Excel Dashboard

## Project Overview
This project is an interactive Retail Sales Performance Dashboard created in Microsoft Excel. The dashboard helps analyze sales, profit, product performance, regional performance, and monthly trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Dashboard Design

## Key Features
- KPI Cards (Sales, Profit, Orders, Quantity Sold, Profit Margin)
- Regional Sales Analysis
- Profit by Region
- Sales by Category
- Profit by Category
- Product Sales Performance
- Salesperson Performance
- Monthly Sales Trend
- Interactive Slicers

## Key Insights
- Office Supplies generated the highest profit.
- Nakuru recorded the highest sales.
- Sales peaked in June and October.
- Peter achieved the highest sales among salespersons.
